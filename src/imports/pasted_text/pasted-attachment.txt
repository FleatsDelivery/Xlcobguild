What a TDZ Error Actually Is

The Temporal Dead Zone happens when JavaScript tries to access a let or const variable before it has been initialized.

Example:

console.log(apiBase) // ❌ TDZ

const apiBase = "/api"


or in React:

const fetchTeams = useCallback(() => {
  fetch(apiBase + "/teams")
}, [])

const apiBase = "/api"   // ❌ defined later


Because useCallback executes during render, the variable must already exist.

Why TDZ Happens a Lot in React

In React apps (especially with Next.js), TDZ errors typically come from:

1️⃣ Hook order problems
const loadData = useCallback(() => {
  fetch(apiBase)
}, [])

const apiBase = "/api"

2️⃣ Circular imports

File A imports File B
File B imports File A

teams-tab.tsx
   imports
team-card.tsx

team-card.tsx
   imports
teams-tab.tsx  ❌


This is a very common source of TDZ.

3️⃣ Constants declared after hooks
state
hooks
callbacks
constants  ❌

Never break that order.

One Huge Rule That Will Save You

Never let shared components import their parent tab.

Bad:

teams-tab
  imports team-card

team-card
  imports teams-tab ❌


Shared components should only import downward, never upward.

Example:

shared/
  team-card
  player-row

tabs/
  teams-tab


Tabs can import shared components, shared cannot import tabs.

This avoids circular imports → avoids TDZ.

Circular imports between files.
